# 熟人约球 · 高保真交互预览

直接打开 `index.html`，无需构建、网络资源或后端服务：

```bash
# 在仓库根目录，macOS
open docs/previews/quick-match-ui/index.html

# 也可启动本地静态服务
python3 -m http.server 8080 --directory docs/previews/quick-match-ui
# 浏览器访问 http://localhost:8080
```

## 怎么看

- 桌面并排显示小李（A）和小王（B）；窄屏通过上方角色按钮切换。
- 左侧控制台/手机顶部可折叠面板切换 **11 个演示场景**。它不是产品界面的一部分。
- 初始展示“已约好”：A在对局页，B在我的页。点击A进入，再让B进入或放弃，观察两边联动。
- “从发起开始”可走完选人、球种、时间、比赛类型、发送和接受。
- “正式比赛”演示单方滑动结束：从左端滑块拖到最右并松手，任意一方都能直接结束，另一方不需要同意。半途松手、触摸取消或点击轨道不会结束。键盘可用方向键或End完成、Escape复位；不提供真实积分结算实现，App/后端的原结束流程尚未修改。
- “同人互邀”“类型不同”“换人接受”分别验证合并、拒绝合并和关闭旧邀请提示。小陈是第三人场景数据，没有第三个手机视图。
- “跨午夜与失效”从次日00:30开始。切到07:00看失效；演示时钟允许倒放恢复自动过期的邀请，方便重复比较，不代表实际业务能撤销过期。
- “仅允许好友约球”把A/B设成非好友最近对手，并把B开关重置为关闭。先开B的开关，再用A发送，观察拦截提示。
- “约球记录 / 对局记录 / 对局详情”可查看终态，点击“再约一场”带入信息但不自动发送。

## 范围

- 所有账户、成绩、好友关系、邀请与通知均为本页模拟数据。设置仅按模拟账户保存在当前浏览器；不代表真实账号已具备跨设备同步。
- 业务状态保存在内存，刷新/切换场景会重新载入样例。模拟时钟初始为北京时间2026年8月25日，不随真实时间流逝。
- 只做亮色预览。扫码、隐藏战绩、协议等原有功能不重新实现，并在界面标明。
- 不调用API，不使用生产登录，不修改数据库。不将原型脚本直接作为App业务代码。
- 静态资源为本目录HTML/CSS/JS，无CDN、外部图片或字体依赖。

## 验证

复用仓库 `app` 已有的 jsdom 开发依赖：

```bash
node --check docs/previews/quick-match-ui/preview.js
node --test docs/previews/quick-match-ui/preview.test.mjs
```

检查覆盖：接受不建比赛、双方进入、拒绝退出、单方滑动结束与双端同步、滑动中断/误点/键盘、互邀类型、换人接受竞争、收到不阻止发送、午夜与失效、好友开关、再约预填和文本转义。

另已用本机Chrome检查11个场景在1440/1024/768/390/320px宽度的横向溢出，并走查双人开局、取消、换人确认、设置拦截、键盘弹层与移动角色切换。滑动结束另经真实浏览器鼠标、手机触摸、触摸取消和键盘检查；终点松手才结束，点击轨道或中途松手不结束。
