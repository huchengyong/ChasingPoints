# 登录页布局间距调整设计

## 目标

减少微信登录页上半区过于贴顶、主文案与底部操作区之间空白过大的观感，同时保持登录按钮区域靠近页面底部。

## 调整范围

仅修改 `app/pages/login/login.vue` 中微信登录页共用的布局间距：

- 将 `.login-container` 顶部内边距由 `44rpx` 调整为 `76rpx`，并继续叠加顶部安全区。
- 将 `.login-content` 最小高度中的固定内边距扣减值由 `76rpx` 调整为 `108rpx`，与新的顶部和底部内边距总和保持一致。
- 将 `.hero-section` 顶部外边距由 `116rpx` 调整为 `156rpx`。

这会让品牌区轻微下移，并让主文案整体更接近页面中部。`.wechat-actions` 继续使用 `margin-top: auto`，因此微信登录和手机号登录按钮仍保持靠底布局。

## 非目标

- 不修改页面模板、文案、登录逻辑或协议交互。
- 不增加插图、装饰或新组件。
- 不改变按钮尺寸、底部安全区或手机号登录模式的结构。

## 验证

- 运行 `app` 现有纯逻辑测试，确认样式改动未影响登录漏斗逻辑。
- 检查页面改动仅包含上述三个相互关联的 SCSS 间距值。
