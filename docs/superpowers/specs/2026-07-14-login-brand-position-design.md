# 登录页品牌区位置修订设计

## 背景

第一次调整后，顶部品牌 Logo 仍与微信小程序胶囊菜单处于同一纵向区域，主文案下方仍有较明显的集中空白。

## 目标

让品牌 Logo 大致从胶囊菜单底部下方开始，同时带动主文案下移，继续保持底部登录按钮靠底。

## 调整范围

仅在 `app/pages/login/login.vue` 的 `.brand-row` 中增加：

```scss
margin-top: 112rpx;
```

不读取胶囊菜单位置，不增加运行时计算。现有 `.wechat-actions { margin-top: auto; }` 保持不变，因此底部操作区仍靠近页面底部。

## 非目标

- 不追求所有机型上与胶囊菜单像素级对齐。
- 不修改登录逻辑、模板、文案或按钮样式。
- 不继续调整页面 padding、内容最小高度或主文案自身间距。

## 验证

- 检查页面 diff 仅新增 `.brand-row` 的 `margin-top: 112rpx`。
- 运行 `app` 全量纯逻辑测试，确认登录漏斗逻辑不受影响。
