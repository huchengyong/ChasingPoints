# 斯诺克与中式八球巡检修复验收记录

日期：2026-11-11。范围：斯诺克（规则版本 2）与中式八球的记分、详情、结算。美式九球、旧版斯诺克、裁判判局、真机与鸿蒙未覆盖。

## 1. 巡检方式

- 本机隔离环境：临时 MySQL 与 Redis、本机编译的后端、占位密钥，不连开发或生产数据。
- 用接口打了 5 场：斯诺克 1 场（3 局，含单杆 123、自由球、连续 Miss 判负、重置黑球、跨局撤销、认输）；中式八球 3 场（练习抢 3、练习自由局数 1:1、排位抢 1 并走结束确认）；另有两场进行中对局用于记分页。
- 微信开发者工具渲染记分页、详情页、结算页、复盘页并截图。

记分规则本身未发现错误：越权记分、赛制未达成就结束、结束确认中记分或撤销都被拒绝，比分与局数正确。
