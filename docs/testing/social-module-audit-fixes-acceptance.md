- 用接口实测好友搜索 / 申请 / 拒绝 / 接受、拉黑、关注、隐藏战绩、约球发送、动态发布与评论。

- 生产库只读核对了社交各表行数与动态开关：动态在生产由合规开关关闭；好友关系、拉黑、约球均为 0 条，无需修数据。

## 2. 发现并修复的问题

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | 拉黑后，只要两人打过球，对方仍能发约球并附留言 | 约球发送资格先查双向黑名单；拉黑时关闭两人之间仍待回应的约球 |
| 2 | "隐藏战绩"只对好友的对手列表生效，交锋统计 / 历史 / 总览带 `target_user_id` 时不检查 | 三个接口返回 `hidden: true` 且不带战绩数据；好友交锋页显示"对方已隐藏战绩" |
| 3 | 关注接口线上可调但产品没有入口：重复关注每次都发通知、可关注不存在的用户、不查黑名单 | 四个接口受动态合规开关控制；校验目标用户与黑名单；只在新建关注时通知 |
| 4 | 拉黑不可撤销，也看不到拉黑了谁 | 新增黑名单列表与移出接口；设置页新增"黑名单"页面 |
| 5 | 好友申请被拒后可无限重发；留言超长只报"发送失败"；发送与接受不是事务；接受时不查好友上限 | 拒绝后 7 天冷却、24 小时 30 条上限、留言 200 字；发送与接受改为锁双方用户的事务；拒绝后清理对应通知 |
| 6 | 搜索用户不转义通配符，`%` 可列出全部用户；结果不带"已申请"状态 | 转义通配符、关键字限长、仅 11 位数字才匹配手机号；返回 `has_pending_request` |
| 7 | 被陌生人反复申请时只能拒绝 | 好友申请卡片新增"更多 → 拒绝并加入黑名单" |
| 8 | 好友、申请、关注、动态列表 `page_size` 无上限 | 超过 100 取 20 |
| 9 | 约球留言超过 200 字时数据库报错 | 服务端校验并给出提示；发起页限 200 字并显示计数 |
| 10 | 好友卡片边缘露出左滑操作区 | 未展开时隐藏操作区 |
| 11 | 通知管理页有"新关注提醒"与"挑战提醒" | 合规模式下隐藏关注项（保存时保留原值）；改名"约球提醒" |
| 12 | 动态：发帖无任何校验；评论不限长、不可删；删除动态残留点赞评论；列表逐条查库；直达链接仍能打开动态页；广场动态的 `is_liked` 恒为 false | 发帖校验内容 / 图片域名与数量 / 类型 / 比赛归属；评论限 300 字与频率、作者或动态作者可删；删除动态级联清理；列表批量查询；合规模式下三个动态页不可用；广场路由解析可选登录身份 |
| 13 | `GetFriendListReq.keyword` 在契约里存在但从未实现、无调用方 | 从契约删除 |

## 4. 本机真实后端复验

- 搜索 `%`、`_` 返回空；手机号精确匹配与昵称匹配正常；发过申请的人带 `has_pending_request`。
- 好友申请：300 字留言被拒并提示；拒绝后重发被冷却拦截，对应通知被清理；反向申请不受影响；并发 5 次只成功 1 次。
- 隐藏战绩：好友查三个交锋接口均返回 `hidden` 且无数据；看自己的交锋不变；取消隐藏后恢复；非好友仍被拒。
- 关注：重复 3 次只产生 1 条通知；不存在的用户、黑名单被拒；动态开关关闭时四个接口返回"暂未开放"。
- 拉黑：待回应约球被关闭；双方都不能再向对方约球；黑名单列表与移出正常，移出后可重新约球。
- 动态（本机打开开关）：空内容、超长、外链图片、10 张图、非法类型、他人比赛、战报缺比赛均被拒；评论超长与 1 分钟第 11 条被拒；评论作者与动态作者可删、第三人不可删；删除动态后点赞评论清零；登录用户在广场看到自己的点赞状态。
- 开发者工具截图：黑名单页、好友申请"更多"、交锋隐藏态、设置入口、通知管理、约球留言计数、动态"暂未开放"，浅色深色均正常；好友卡片不再露边，模拟左滑后"拉黑 / 删除"正常出现。
