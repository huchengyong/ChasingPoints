# 品牌主题重构设计

## 背景

当前项目的品牌识别出现了明显分裂：

- Logo 采用高亮金黄底与白字，视觉气质偏“竞技、胜负、聚焦、记忆点强”。
- App 全局主色仍然是绿色，亮暗主题都围绕球台绿展开。
- 欢迎页已经开始使用金黄色主按钮，但进入主流程后又回到绿色主品牌语义。

这会让用户感知到两个不同的品牌系统：一个是欢迎页与 Logo 的“金色品牌”，另一个是应用内页面的“绿色产品”。如果继续维持现状，Logo 的品牌势能很难向应用内沉淀。

## 目标

- 建立与 Logo 一致的品牌主色体系，让用户从启动到核心页面都感知为同一个产品。
- 保留绿色在台球语境中的合理性，但将其从“品牌主色”降级为“语义色 / 状态色”。
- 尽量不改变现有信息结构和交互结构，只做品牌层与主题层重构。
- 在亮色与暗色主题下都保证层级、对比度和可读性稳定。

## 非目标

本次设计明确不包含以下范围：

- 首页结构重做
- 字体体系重做
- 图标风格重画
- 页面布局大改
- 管理后台视觉重构

## 现状诊断

当前主题入口主要集中在以下位置：

- `app/theme.json`：全局 light / dark 主题 token
- `app/App.vue`：页面级 CSS 变量
- `app/store/theme.js`：导航栏、TabBar 颜色切换
- `app/uni.scss`：uni-app 组件默认主题变量

问题主要有四类：

### 1. 品牌主色与 Logo 不一致

全局 `primary` 仍为绿色，但欢迎页主按钮使用金黄色。品牌色没有单一决策点。

### 2. 绿色承担了两种语义

当前绿色既表示“品牌主色”，又表示“成功 / 在线 / 进行中 / 正向反馈”。这会让重要按钮、激活状态、胜率上升、比赛进行中等信息在视觉上混成一类。

### 3. 底色偏冷，难以承接金黄色品牌

现有浅色背景、边框和文字偏冷绿灰，与 Logo 的金黄气质不够同源；暗色主题则偏冷黑绿，也不利于承接金色高光。

### 4. 主题 token 与硬编码并存

虽然项目已经有 `theme.json` 和全局变量，但大量页面仍然直接写死 `#18b05b`、`#22c55e`、绿色渐变与绿色图标色。即使改了 token，也不会立刻全局统一。

## 设计结论

采用“金主绿辅”的平衡方案：

- 金黄系作为品牌主色，负责品牌识别、主要 CTA、主选中态、荣誉类表达。
- 绿色保留为功能状态色，负责成功、进行中、正向增长、在线状态。
- 亮色与暗色底色整体转向“暖中性”，让黄白 Logo 能自然融入页面环境。

这是对当前项目最稳妥的路线：既能统一品牌，又不会因为“全站纯黄”导致界面躁动、廉价或难以阅读。

## 品牌色体系

### 品牌主色

建议将 UI 中的品牌金定义为较稳的金色，而不是直接全量使用 Logo 黄：

- `brandPrimary`: `#E0AE12`
- `brandStrong`: `#C69200`
- `brandSoft`: `#F7E7A8`
- `brandTint`: `rgba(224, 174, 18, 0.14)`

其中：

- Logo 与欢迎页大按钮可以继续保留更亮的黄值，以维持冲击力。
- App 内常规按钮、选中态、标签和高亮数据建议使用 `brandPrimary` 与 `brandStrong`，避免过刺眼。

### 语义色

- `success`: `#18B05B`
- `successSoft`: `rgba(24, 176, 91, 0.12)`
- `info`: 保留现有蓝色体系
- `danger`: 保留现有红色体系
- `warning`: 调整为更偏橙的 `#F97316`，避免与品牌金冲突

## 亮暗主题建议

### 亮色主题

- `background`: `#FAF8F2`
- `backgroundTranslucent`: `rgba(250, 248, 242, 0.82)`

- `cardBorder`: `#E9E2CF`

## 使用规则

### 金色应该出现的位置

- 主要按钮
- Tab 当前选中态
- 首页或个人页的主入口
- 荣誉、等级、勋章、赛季高光
- 关键统计中的第一优先级数字

### 绿色应该出现的位置

- 进行中
- 已完成 / 成功
- 正向增长
- 在线 / 可用状态
- 与台球桌、比赛进行态直接相关的功能标签

### 不建议的用法

- 不要再把绿色同时用于“品牌 CTA”与“成功提示”
- 不要把金色同时当作“品牌主色”和“警告色”
- 不要在一个卡片内大面积并列使用高饱和金和高饱和绿

## 落地范围

### 第一阶段：品牌入口统一

- `app/theme.json`
- `app/App.vue`
- `app/store/theme.js`
- `app/uni.scss`
- `app/pages/welcome/index.scss`

这一阶段完成后，用户从启动页、导航栏、TabBar 到主要 CTA 都会感受到统一的品牌语气。

### 第二阶段：高频页面收口

优先清理首页、登录页、个人页、战绩页、赛季页等高频页面里的硬编码绿色。

### 第三阶段：余量页面补齐

逐步替换子页面、弹窗、列表和详情页中的硬编码色值，最终让主题 token 成为唯一可信来源。

## 风险与取舍

- 风险一：如果把所有绿色都换成金色，信息语义会变差。因此必须保留绿色作为语义色。
- 风险二：如果只改 `theme.json` 而不清理硬编码，整体效果会“半统一”。因此需要按页面分阶段收口。
- 风险三：纯亮黄在浅底上对比度不稳定，所以 UI 品牌金需要比 Logo 黄略深。

## 推荐结论

本项目应从“绿色品牌 + 欢迎页金色点缀”升级为“金色品牌 + 绿色语义”体系。

这不是一次激进重设计，而是一次品牌归位：

- 让 Logo 真正成为应用内品牌的起点
- 让绿色回到它最擅长的状态表达角色
- 让产品整体更统一、更有记忆点，也更像一个成熟的竞技类应用
