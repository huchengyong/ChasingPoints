## Why

追分每一场比赛都需要两个注册用户，球台对面的那个人是最主要的新用户来源。但现在这条路是断的：匹配二维码的内容是裸的签名 token（`get_match_q_r_code_logic.go`），没装追分的人用微信扫只会看到一串字符；他只能先自己搜小程序、注册、找到扫码入口、再扫一次。整个小程序没有注册 `onShareAppMessage`，右上角「转发」不可用；战报海报只能存相册，上面也没有任何入口。

产品还没上线、没有外部老客户端，现在是修好这个闭环成本最低的时候。

## What Changes

- **匹配码改成各端都能扫的普通链接二维码**，内容形如 `https://www.zhuifen.cn/go/?j=<短码>`：
  - 微信扫一扫：通过「扫普通链接二维码打开小程序」规则直接进入小程序承接页。
  - 追分小程序和鸿蒙 App 的端内扫码：识别链接并取出短码，进入原有确认流程。
  - 系统相机或其他 App 扫码：打开官网兜底页，引导用微信扫码或下载。
  - 不使用微信圆形小程序码：它只有微信能识别，鸿蒙 App 扫不了。
- **短码映射现有签名 token**：服务端每次签发匹配码时生成高熵短码，存到 Redis，有效期跟着 token 走（当前 5 分钟）。token 的签名、校验和开局规则都不变。
- **未登录也能预览邀请**：新增匿名接口，凭短码返回邀请人昵称、头像和过期时间（不返回 token 和用户 ID），并按 IP 限流。新用户先看到「谁在约你」，再决定登录。
- **登录后自动继续**：承接页走现有登录页（微信手机号快捷登录），返回后用新增的登录态接口把短码换成 token 和预览，再交给现有确认页 `scanConfirm` 开局。
- **分享卡片**：首页、赛果页、对局详情页注册 `onShareAppMessage`。公开对局分享出去是带比分的卡片，打开后进入观战详情；私密对局只分享不含比分的通用卡片。
- **观战页加未登录引导**：未登录的人从卡片打开观战详情时，底部显示「用追分记录你的比赛」，点击进入登录。
- **海报带二维码**：战报海报和交手报告海报在本地绘制入口二维码。公开对局指向该场观战详情，私密对局和交手报告指向首页。
- **官网**：新增 `/go/` 兜底页；放置微信规则校验文件；下载页和常见问题改成如实展示「微信小程序 + 鸿蒙」，不再承诺 iOS/Android 下载。
- **BREAKING（仅内部）**：`GetMatchQRCodeResp.qrcode_data` 从裸 token 改为链接。端内扫码继续兼容裸 token，但旧版本客户端扫不了新码；目前没有外部用户，只影响开发和测试设备上的旧包。

不在本期：微信圆形小程序码；分享到朋友圈（单页模式不能登录）；鸿蒙 App Linking（系统相机直接拉起 App）；公开交手记录页（涉及 `hide_match_record` 隐私规则）；裁判码改为链接；渠道来源统计；任何与分享挂钩的奖励（违反微信诱导分享规范）。

## Capabilities

### New Capabilities
- `universal-entry-links`: 统一入口链接的格式与解析，小程序承接页按链接类型分发，微信扫码规则，官网兜底页，以及官网下载口径。
- `scan-to-join`: 匹配码短码的签发、有效期与映射，匿名邀请预览与限流，登录后继续开局，端内扫码对链接码和裸 token 的兼容。
- `match-share-entry`: 首页、赛果页、对局详情页的分享卡片规则，观战页的未登录引导，以及战报和交手报告海报上的入口二维码。

### Modified Capabilities

（无）现有扫码开局的确认、球种与对局类型选择、开局校验规则都不变；`quick-match-invites`（约球）不受影响。

## Impact

- 后端：`chasing_points.api` 新增匿名预览接口（`/api/public` 组）和登录态短码兑换接口（`/api/match` 组），`qrcode_data` 改为链接，`MatchShareData` 新增 `visibility`；新增 Redis 短码存储和匿名接口的 IP 限流；改完 `.api` 需要运行 goctl。不改表结构。
- UniApp：新增链接承接页；`match-scan.js` 支持解析链接；`quick-scan.js` 支持由承接页直接交接给确认页；首页、赛果页、对局详情页加分享回调；观战页加未登录引导；`posterGenerator.js` 绘制二维码。
- 鸿蒙：同一套 UniApp 代码，端内扫码能识别链接码；分享卡片仅小程序生效，鸿蒙继续靠保存海报分享。
- 原生 iOS：目前没有扫码和匹配码功能，不受影响。
- 官网：新增 `/go/` 页面、微信校验文件，修改下载页和常见问题。
- 外部配置（需要用户操作）：微信公众平台配置「扫普通链接二维码打开小程序」规则、下载校验文件；确认小程序主体已认证（手机号快捷登录的前提）。
